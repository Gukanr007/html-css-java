# Personal Portfolio Website

## 🌐 Project Description
A simple and responsive **Personal Portfolio Website** made using HTML5, CSS3, and basic JavaScript. This static site showcases your personal information, skills, education, and contact details — like a digital resume.

## ✨ Features
- Clean "About Me" section
- Skills list and projects section
- Education background
- Contact form layout (non-functional)
- Responsive design for mobile and desktop

## 🛠️ Technologies Used
- HTML5
- CSS3 (Flexbox, Grid, Media Queries)
- JavaScript (optional scroll or alert functionality)

## 📂 File Structure
```
PortfolioWebsite/
├── index.html
├── style.css
├── script.js (optional)
├── /images
```

## 📸 Sections Included
- Header with name and navigation links
- About Me section with short intro
- Skills and Projects in grid format
- Education timeline
- Contact section with form

## ▶️ How to View
1. Download or clone the repository.
2. Open `index.html` in any web browser.

## 📘 Learning Outcomes
- Hands-on HTML/CSS page building
- Basic responsive web design
- Understanding structure and styling
